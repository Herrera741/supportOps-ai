
# SupportOps AI

An AI-assisted customer support request management platform.

## Overview

SupportOps AI is an enterprise software portfolio project developed to demonstrate Forward Deployed Engineering (FDE) skills.

The project simulates an engagement with a fictional customer support organization that needs a centralized solution for managing incoming customer requests.

The development process emphasizes customer discovery, requirements engineering, domain modeling, API development, database integration, AI-assisted workflows, testing, and deployment.

## Business Problem

Customer support employees need an efficient way to create, track, search, and manage support requests.

Without a centralized system, organizations may experience:

- Difficulty tracking request ownership
- Inconsistent request prioritization
- Delays locating existing customer requests
- Limited visibility into request status
- Incomplete customer information

## Proposed Solution

SupportOps AI will provide a centralized application where employees can:

- Create and update support requests
- Associate requests with customers
- Assign requests to employees
- Track request status and priority
- Search requests using customer or reference information
- Filter requests using multiple criteria

Future capabilities will include AI-assisted request classification and prioritization.

## Planned Technology Stack

- Backend: Python and FastAPI
- Database: PostgreSQL
- Frontend: React and TypeScript
- AI Integration: OpenAI API
- Testing: pytest
- Deployment: Docker and cloud hosting
- Version Control: Git and GitHub

The technology stack may evolve as implementation requirements become clearer.
